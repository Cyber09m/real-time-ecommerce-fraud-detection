# Contributing

Thanks for your interest in contributing to this project! We welcome bug reports, feature requests, and pull requests.

Contributions guide:

1. Fork the repository and create a feature branch from `main`.
2. Write clear, focused commits and include tests where appropriate.
3. Run existing tests: `cd backend && npm test`.
4. Open a pull request with a descriptive title and summary of changes.

We use a simple code of conduct and expect contributors to be respectful and collaborative.
